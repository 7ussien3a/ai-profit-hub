# Source Index

Store concise source notes in this folder. Do not copy complete copyrighted articles.

## Source Standards

- Prefer primary and official sources.
- Record the publication date and access date.
- Distinguish verified facts from editorial analysis.
- Cross-check material claims when a second authoritative source is available.
- Mark rejected or conflicting evidence clearly.
